# Whisper | ويسبر

قناة موثوقة بين الشركات: كل رسالة **سرّية**، **سليمة**، ومن **مرسلها الحقيقي**.

ويسبر يستخدم مفتاح تشفير خاص لكل شركة يعطي ثلاث ضمانات:

| الضمان | وش يسوي | وش يحمي منه |
|---|---|---|
| السرّية | يقفل الرسالة (AES-256-GCM) | تسريب العقود وعروض الأسعار |
| السلامة | يختم الرسالة، وأي تعديل يكسر الختم | تغيير مبلغ أو رقم في فاتورة |
| الهوية | يوقّع الرسالة بمفتاح الشركة الموثّق | انتحال المورد وتغيير الآيبان |

## الموقع
صفحة واحدة `index.html` فيها تجربة تشفير حقيقية داخل المتصفح (Web Crypto API) وتجربة تفاعلية لاحتيال تغيير الآيبان.
